Unsaved
Offline SoE only Close Sanctuary of Exile first. Load the .d2s and pd2_shared.stash from %USERPROFILE%\Documents\Diablo II\Saves. Edit stats, skills, quests, inventory, and shared stash. Always keep a backup.

Save downloaded

  1. Make sure Diablo II / SoE is fully closed.
  2. Overwrite the matching .d2s in Documents\Diablo II\Saves.
  3. Launch SoE and confirm the character loads.

Load a Sanctuary of Exile .d2s

Drag and drop your character .d2s or pd2_shared.stash, or click Load Save. Path: Documents\Diablo II\Saves

Character

Changing level updates the header and the stats block. Set exp to this level writes the official LoD total so the game does not rewind you.

Attributes

Base saved stats. Item bonuses are not stored here — the game adds those on load.

Class skills

PD2 / SoE names, in save-file order, grouped like the in-game trees. Hard points only (no +skills from items).

Quests, difficulties, waypoints

Unlocks act travel, all waypoints, and marks every quest complete so you can make games in Normal / Nightmare / Hell.

Rewards granted only for quests that were not already complete: Den of Evil +1 skill, Radament +1 skill, Izual +2 skills, Lam Esen +5 stats, and Malah’s Scroll of Resistance (+10 all resist) — each per difficulty (up to +30 all res). Also sets every difficulty to Act 5 so Harrogath and the Act 5 waypoint list actually show in-game.

Items & stash

Load a character and/or pd2_shared.stash. Spawned runes/gems/potions go into the first free inventory cell.

Selected item

Click an item, then click an empty cell to move it.

Spawn into current grid

Shared stash is the separate pd2_shared.stash file — save it as well as the character. Socketed gems stay glued to their parent. Close SoE before overwrite.
