If SoE is running it will overwrite this file when you leave a game, and these edits will vanish.

Save downloaded

  1. Make sure Diablo II / SoE is fully closed.
  2. Overwrite the matching .d2s in Documents\Diablo II\Saves.
  3. Keep backups as .d2s.bak (Downloads is fine). Never put a second .d2s in Saves — that shows as a duplicate character.
  4. Launch SoE and confirm the character loads.

Load a Sanctuary of Exile .d2s

Drag and drop your character .d2s or pd2_shared.stash, or click Load Save. Path: Documents\Diablo II\Saves

Character

Changing level updates the header and the stats block. Set exp to this level writes the official LoD total so the game does not rewind you.

Attributes

Base saved stats. Item bonuses are not stored here — the game adds those on load.

Class skills

PD2 / SoE names, in save-file order, grouped like the in-game trees. Hard points only (no +skills from items).

Quests, difficulties, waypoints

Unlocks act travel, all waypoints, and marks every quest complete so you can make games in Normal / Nightmare / Hell.

Skipping the cube quest means Cain never hands you one, so Unlock everything also puts a Horadric Cube in inventory (or personal stash if inventory is full). Rewards granted only for quests that were not already complete: Den of Evil +1 skill, Radament +1 skill, Izual +2 skills, Lam Esen +5 stats, and Malah’s Scroll of Resistance (+10 all resist) — each per difficulty (up to +30 all res). Marks Act 4 as finished (that is what actually opens Act 5) and sets every difficulty to Harrogath. Town portal scrolls always return to your current act’s town — use the waypoint, or start a new game after saving.
