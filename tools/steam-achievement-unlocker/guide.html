Steam Achievement Unlocker

Local Node CLI · Back to hub

Achievements can’t be unlocked from the browser. This is a small local Node.js tool that talks to the Steam client via Steamworks. Default game: State of Decay 2 (AppID 495720). Any owned AppID works.

Requires Steam running & logged in, Node.js 18+, and ownership of the game. Close the game before unlocking. Use at your own risk — some online games may treat this as cheating.

Setup (once)

  1. Install Node.js.
  2. Open a terminal in tools/steam-achievement-unlocker.
  3. Run npm install.

On Windows you can also double-click unlock.bat (it runs npm install if needed, then lists achievements).

Commands

cd tools/steam-achievement-unlocker
npm install

:: List SoD2 achievements
node unlock.js --list

:: Unlock everything for SoD2
node unlock.js --unlock-all

:: Unlock one by API name
node unlock.js --unlock YOUR_ACH_API_NAME

:: Lock / clear all
node unlock.js --lock-all

:: Another game (AppID or preset)
node unlock.js --app 480 --list
node unlock.js --app sod2 --locked-only

Presets

  • sod2 / state-of-decay-2 → 495720
  • spacewar → 480 (Steam test app)
