Inventory

Items found in the main inventory table.

Stack counts of items you own can be changed (1 to 99); the game may cap some items at its own maximum. New consumables / key items can be added below (tested in-game). The game will not show brand-new weapons or armor inserted into a save, so weapons and armor work by changing one you already own: pick any spare weapon or armor piece in the table and type what it should become in its "change into" box. Own a few cheap spare weapons first (buy some in the Hunter's Dream), then turn them into the ones you want. Weapon-to-weapon and armor-to-armor only. Always keep a backup.

    Notes

    What this editor does and does not do.

    TipDetail
    Which fileOnly the unencrypted main save userdata0000 of the bbport PC port (1,310,720 bytes). Real PS4 saves are encrypted and will be refused.
    Game openClose the game fully before installing; it autosaves and will overwrite your edit. Install refuses if the file changed on disk since you loaded it.
    BackupsInstall to Save Folder first writes the original into a bb_editor_backups folder inside the folder you picked, then replaces the save and re-reads it to verify.
    LevelStored separately from the stats. Use the Level button to keep it matching (total of the six stats minus 50, inferred from one save).
    Max HPNot stored directly; the game recalculates it from Vitality. Rest or re-equip after loading.
    Offline onlyDo not use edited characters online or in co-op / PvP.
    InventoryCounts of owned stackable items can be edited. Adding new items is not wired yet; it needs a before/after save comparison to be safe.
