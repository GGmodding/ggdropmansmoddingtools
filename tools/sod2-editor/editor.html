Morale

Community morale meters are sparse in saves — many “Morale_*” strings are effect IDs, not editable floats. Survivor fatigue (rest) is under Survivors → Vitals. Difficulty / legacy / map mode are not stored as simple community fields in typical DaytonSaveGame files (often baked into scenario assets).

Community display name edits the freeform TextProperty fragment when present (loc key stays). Parts uses CommunityResources key 5 — verify in-game. Unavailable = not in this save.

Survivors

Vitals, identity, traits, skills, and equipment. Names use localization TextProperty — editable when a freeform display fragment exists.

Select a survivor

Details appear here.

Identity

First/Last/Nick only edit when the save stores a plain display string. Voice, culture, body definition, hero bonus, and standing are always writable when present.

Vitals

Health/stamina are raw floats (often ~100). Fatigue, addiction, sickness, plague timer, trauma → 0 to clear. Plague rate is the infection pace value from the save.

Traits

# TraitResourceID

Changing a trait ID rewrites the NameProperty (length can change). Adding clones the smallest existing non-Default trait on that survivor, then sets the new ID.

Skills

# SkillResourceID Level XP

Skills use SurvivorSkillSave (ID + CurrentLevel + CurrentXP). Game max is usually 7. Adding clones the smallest skill on that survivor, sets the new ID, and levels it to 7.

Slots store an Index into the primary locker’s ItemOrder (−1 = empty). Assign any locker item index, or clear. Stack/durability still live on the locker item itself (Inventory tab).

Inventory / lockers

Supply locker ItemLibrary contents: edit stacks & durability, change class, duplicate, remove, or add by cloning a template. New item types need a valid /Game/Items/... path already known to the game.

Item catalog (from this save)

Short name Path

Catalog is harvested from ItemLibrary class lists in this file. Use Use to fill the Add class field below. Facility mods appear under the FacilityMod category. Vehicle trunks and survivor bags are separate ItemLibraries in the locker list (look for vehicle/character labels).

Select a locker

Items appear here.

# Item Stack / Durability Class #

Duplicate clones the row. Add picks a small template in that category and retargets its ClassIndex (adding the class path to the locker if needed). Invalid paths can soft-break the locker — backup first.

Map / Quests

Reveal map sites (ScoutedLevel), reset radio cooldowns, and browse loose missions. Radio “unlock” in this save format is mostly cooldown/charges on the Availability list.

Map sites

# Scouted level Outpost ID Surveyed Infested

Levels: Hidden → Revealed → Scouted → Advanced. Bulk reveal rewrites every site (can take a moment on large maps).

Vehicles

Repair, refuel, swap models, reveal on map, teleport near base, edit trunk slot indices, duplicate / delete. Trunk items live in the vehicle ItemLibrary (also listed under Inventory).

Select a vehicle

Stats, class, position, trunk.

Trunk slots

# Item ItemOrder #

Trunk Index points into the vehicle ItemLibrary ItemOrder (−1 = empty). Duplicate clones the whole vehicle with a new Guid. Teleport parks cars in a grid around a guessed base cluster.

Base / Facilities

Edit current homesite FacilitySlotSaves: swap facility asset paths, set state, repair. Homesite slot templates from other bases are listed below (read/edit carefully).

Select a facility

Slot details.

Swapping facility rewrites the AssetObject path (use catalog paths from this save). Built-ins and parking still “work” as slots but odd swaps can clip geometry in-game — backup first. Facility mods are inventory items in the FacilityMod category (Inventory tab).

Homesite templates

# Slot ID Facility State

HomesiteSlots stores facility layouts for known bases (often prior homes). Editing here does not always change your current base — use the list above for the live slot set.

Presets

One-click bundles that touch several tabs at once. Always backup first — especially full-comfort.

Presets call the same APIs as the manual tabs. Results show in the status bar. Re-open tabs after applying to see updated values.
