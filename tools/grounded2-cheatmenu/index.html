Install

Use a UE4SS experimental / UE5 build. A ue4ss\Mods folder alone is not enough — you need dwmapi.dll and ue4ss\UE4SS.dll next to the shipping exe.

  1. Unzip the download.
  2. Copy GGDropmanCheatMenu into ...\Grounded2\Augusta\Binaries\Win64\ue4ss\Mods\
  3. Copy UE4SS_Signatures\StaticConstructObject.lua into ...\ue4ss\UE4SS_Signatures\ (create the folder if needed).
  4. In UE4SS-settings.ini set:
bUseUObjectArrayCache = false

[EngineVersionOverride]
MajorVersion = 5
MinorVersion = 6

Start Grounded 2, load into a world, confirm ue4ss\UE4SS.log shows [GGDropmanCheatMenu] ready, then press F8.
