Unsaved
Chrome tip Steam saves live under Program Files — folder pickers often say “system files” and refuse. Use Open Folder, copy slot00xx to Desktop, then Load Folder / Find Save on the copy — or Load Files (multi-select the files inside the slot) / Load ZIP. Always backup first.

ZIP downloaded

  1. Make sure Subnautica / Below Zero is fully closed.
  2. Extract the ZIP — you should get a slot00xx folder.
  3. Copy its contents into your real slot folder (overwrite).
  4. Launch the game and load that slot.

Load a save slot

Chrome blocks folders inside Program Files. Prefer Load Files (Ctrl+click the files in slot00xx), or copy the slot to Desktop and use Load Folder / Find Save, or zip the slot and Load ZIP.

NG+ / story tools

        
Bases & vehicles live in global-objects.bin. Story PDA / wreck triggers live in scene-objects.bin. Full NG+ usually means swapping scene-objects from a fresh same-mode save.

      

      

        Dropping scene-objects from the ZIP does not invent a fresh story file — after extract, copy scene-objects.bin from a brand-new slot into this one, keep global-objects.bin from your old progress, and set gameTime to 0.
